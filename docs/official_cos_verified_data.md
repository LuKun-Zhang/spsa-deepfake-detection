## 协议说明

- **官方完整协议**：`nEpochs: 5` → epoch 循环 `range(0, 6)` **含端点**，实际 **6 周期** E0–E5；
  `lr_scheduler: cosine`，`lr_T_max: 5`（cosine T_max=5）。训练 lr 逐周期衰减：
  E0=100% / E1=90.5% / E2=65.5% / E3=35% / E4=10% / E5=0.5%（`lr_eta_min: 1e-6`）。
- **SPSA1SWA**：`spsa: true` + `SWA: true`，`swa_start: 3` → SWA 逐 iter 收集 **E4/E5**（`epoch > swa_start` 严格大于）。
- **CTRL**：`spsa: false` + `SWA: false`，其余完全相同（同 seed、同数据、同优化器）。
- 3 个 seed：**s1024 / s2048 / s4096**（`manualSeed`）。数据集：FF++（F2F/DF/FS/NT）训练，Celeb-DF-v2 测试。

## 主指标口径

- **7 点 mean**：训练中当期测试 auc 按 step 去重后，`step >= 5743` 的**前 7 个**测试点平均
  （对应 E0末/E1中/E1末/E2中/E2末/E3中/E3末）。官方日志实际有 12（SPSA1SWA）/11（CTRL）个测试点。
- **best**：全程单个 epoch end 的最高测试 auc。
- **SWA-Final**：训练结束后 `Iter Final for SWA` 的 swa.pth 部署形态测试 auc（SPSA1SWA 专属；CTRL 无 SWA，记 `-`）。
