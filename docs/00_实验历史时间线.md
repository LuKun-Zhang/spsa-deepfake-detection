## 2. 阶段二：cons 修复与 E 系列（8-18 晚 ~ 8-19）

- **仍有效**：机制证据（E1 建立一致性无作弊）与消融方向（NT-Xent 必要、SWA 冲突、λ/temp 峰值）不依赖单次 AUC。

## 3. 阶段三：统计验证 v1（8-19 23:55 ~ 8-20 07:25）⚠️ 关键

| 项目 | 内容 |
|---|---|
| 目的 | 首次用多运行统计验证 cons 增益（A vs E 各跑多次） |
| 实验 | **A 类 ×3 + E1 类 ×3**（共 6 次，第 6 次 E1c 被 watcher 按计划终止，实际 **5 次**） |
| A 结果 | {0.7183, 0.7193, 0.7230} → **mean 0.7202 ± 0.25 点** |
| E1 结果 | {0.7403, 0.7311} → **mean 0.7357 ± 0.65 点**（n=2） |
| 差距 | **Δ = 1.55 点**，分布不重叠（E 最低 0.7311 > A 最高 0.7230） |
| 效应量 | Cohen's d = **3.65**（极大效应） |
| 显著性 | 置换检验 **p = 0.098**，未达 0.05 |

**结论**：
1. **方向证据强**：Δ=1.55 点（超 1.5 门槛）、分布零重叠、d=3.65 —— cons 有效的信号非常强。
2. **显著性未达标**：p=0.098 > 0.05，不能下"有效"定论。根因是 **E 类只有 2 个样本**，置换检验功效不足；E1c 被砍恰是救显著性那一次。
3. 该次运行于 seed 完全锁死之前，组内波动（A std 0.25、E std 0.65）仍含残留随机性；E 波动更大或与 cons 放大敏感有关（待 v2 验证）。

## 4. 阶段四：确定性修复 + 统计验证 v2（8-20，进行中）

### 4.1 做了什么改动（针对什么问题）
修复目标：把训练全链路的随机性锁死，让"同配置 = 同结果"，统计比较才可信。

| # | 改动 | 针对的"漏网随机源" |
|---|---|---|
| 1 | `init_seed` 补 `np.random.seed(manualSeed)` | numpy 全局 RNG 不受 manualSeed 控制 |
| 2 | 新增 `seed_worker` 挂到 train/test DataLoader | 8 个 worker 子进程随机状态失控 |
| 3 | `seed_worker` 内对 albumentations `Compose` 实例调 `set_random_seed` | **元凶**：增强库实例 RNG 从系统熵初始化，外部 seed 无效 |
| 4 | yaml `cudnn: false` + `cudnn.deterministic=True` + `use_deterministic_algorithms` + 启动前缀 `CUBLAS_WORKSPACE_CONFIG=:4096:8` | GPU 卷积/归约的浮点非确定性 |

### 4.2 确定性验证结果
- DataLoader 双跑：**逐位一致** ✅
- GPU 短训冒烟双跑（3 batch 前向+反向+step）：**loss 逐位一致** ✅（第 4 项修复前仅差 1e-6）

### 4.3 当前任务
- chain 已启动（8-20 10:29）：`stat_A_s1024 → E_s1024 → A_s2048 → E_s2048 → A_s4096 → E_s4096`，每次约 2h，共约 12h。
- 每个实验记录 4 个 epoch 的测试 AUC（固定 epoch 报数，不引入验证集）。
- 目的：补齐 E 第 3 样本 → 配对比较 mean±std + 置换检验；若 v1 信号保持，p 应从 0.098 降至显著区间。
