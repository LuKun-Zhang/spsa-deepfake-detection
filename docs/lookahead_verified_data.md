## 1. 与 EMA 臂的关键口径差异（本臂刻意修正）

| | 7 个训练测试点测什么 | Final | 与 CTRL 逐点可比 |
|---|---|---|---|
| **EMA 臂** | EMA 平均权重（swap 到 `_ema_sd`） | EMA 终权重 | ✗ 早期点带 lag 伪影 |
| **Lookahead 臂** | **online (fast) 权重**（不 swap） | **slow 权重**（部署物 `la_slow.pth`） | ✓ 同口径 |

Lookahead 训练时 fast 每 `la_k` 步被拉回 slow（`slow += alpha*(fast-slow); fast = slow`），7 点测的就是这个 fast 轨迹——与 CTRL 测 online 轨迹同约定，因此本臂的 7pt 配对增益可直接与 SAM / 主表 2×2 并排，不重蹈 EMA 的度量滞后。

- **结论**：三 seed 全带内（+1.00 / +0.41 / −0.44，均值 +0.32）→ **Lookahead 无增益**。
