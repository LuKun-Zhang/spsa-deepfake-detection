# SAM 替代方法臂 — verified data（受控 4-cycle，纯 detector + SAM，3 seed）

**结论**：SAM 臂 7pt-mean 配对增益 **+0.23 / −0.63 / +1.24 → mean +0.28**（×1e-2），落在受控 seed
噪声带（±0.95）内，判定为**无可复现增益**，与论文对 SPSA+SWA 超加性的"非平凡来源"论证相对照。

**实验设定**（见 `configs/stat_sam_s{1024,2048,4096}.yaml`）：受控 4-cycle（`nEpochs: 3`、cosine
`lr_T_max: 3`、Adam 同主方法超参），**唯一变量 = 扰动机制**：optimizer `type: sam`（adam-base,
`rho: 0.05`），`spsa: false`、`SWA: false`（SAM 臂不含 SPSA 亦不含 SWA，测 online 权重）。
配对 CTRL = 同 seed 纯受控（`stat_ctrl_s*.yaml`）。
